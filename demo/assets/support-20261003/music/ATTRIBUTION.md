# Music Library — Attribution (REQUIRED)

**Usage note for agents:** query this library with `bin/music-pick.py <mood>` (moods:
`dark-tension`, `tech-driving`, `upbeat-bright`, `calm-ambient`, `epic-cinematic`).
The picker reads `assets/music/index.json`. Any published video that uses a track from
this directory **must** carry the attribution below (video description or end card).

## Required attribution string

Every published video using any track here must include:

```
Music: Kevin MacLeod (incompetech.com)
Licensed under Creative Commons: By Attribution 4.0
https://creativecommons.org/licenses/by/4.0/
```

Better (per-track form): `"<Track Title>" Kevin MacLeod (incompetech.com), Licensed under Creative Commons: By Attribution 4.0, https://creativecommons.org/licenses/by/4.0/`

Source: Internet Archive mirror of Incompetech (https://archive.org/details/Incompetech).
Re-encoded to 192k MP3 44.1kHz stereo; audio content unmodified.
